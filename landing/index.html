Publish a folder.
Share a link.

No server, no DNS, no hosting account. The site stays online while some peer hosts it: your terminal, or a machine running pin.

npm install
node bin/linda-net.js publish example
# linda://1y9nut63…   (keeps seeding)

Two ways to share

Sites

Copy a folder of static files into a Hyperdrive. Readers open it in a browser; it works even when the author is offline, as long as some peer hosts it.

linda-net publish ./site
linda-net serve
# http://<key>.localhost:7777/

Tunnels

Share a live TCP port (HTTP, SSH, a database) with no public IP or port forwarding. Works while the exposing machine is online.

linda-net expose 3000
linda-net connect linda-tunnel://… --port 3000

Good to know

  • Private sites: publish --private encrypts the drive; the key is the part after #.
  • Verified: every block is checked against the site's public key.
  • Isolated: each site gets its own origin, so sites can't read each other's cookies.
  • Not anonymous: peers you connect to can see your IP. Links and tunnel links are secrets: share with care.
  • publish and serve on one machine need different --storage dirs.
